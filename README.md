# HypothesisTestingProject

Проект по статистической проверке гипотез на финансовых данных.

## Описание
В репозитории представлены Python-скрипты для анализа данных и проверки гипотез. 
Исходные данные находятся в файле `BRENT_M5_201304022200_202502051135.csv`.

## Установка и запуск
1. Установите зависимости (если они есть в `requirements.txt` или перечислены в коде).
2. Запустите основной скрипт: `python work_file.py`
